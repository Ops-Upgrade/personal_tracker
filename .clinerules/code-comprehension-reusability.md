## Brief overview
  Rules requiring full codebase comprehension before writing new code, and maximizing reuse of existing implementations. Applies globally across all workspaces.

## Code comprehension
  - Always read the entire code context before writing new code. Never assume functionality based on standard patterns or conventions.
  - When asked to implement new features, always read the whole codebase first to understand the existing architecture, patterns, and available utilities.

## Reusability
  - Identify and utilize existing reusable elements before writing new code. Do not bloat the codebase by re-implementing functionality that is already available.
  - Before creating a new utility, component, or helper, search the codebase for something that already serves the same or similar purpose.
