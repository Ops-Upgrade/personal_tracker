## Brief overview
  Rules requiring root-cause analysis and thorough debugging rather than surface-level hotfixes. Applies globally across all workspaces.

## Root-cause debugging
  - When performing error debugging, do not perform a hotfix or patch just to solve the surface-level issue.
  - Always trace back to the root cause of the issue and solve the problem from its absolute root.
  - After identifying the root cause, verify the fix doesn't introduce regressions by reviewing all affected code paths.
