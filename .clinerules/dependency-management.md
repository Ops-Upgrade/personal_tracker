## Brief overview
  Rules for managing dependencies, verifying package versions, and ensuring tooling choices are current and secure. Applies globally across all workspaces.

## Version verification
  - When planning an implementation, always search the internet for the current version of tools and packages before adding them.
  - Always verify if a selected package is deprecated. If it is, identify the modern alternative currently being used by developers.

## Package selection
  - Always select the latest and most secure versions of packages.
  - Prefer actively maintained packages with a strong community and regular release cadence over stale or minimally maintained alternatives.
