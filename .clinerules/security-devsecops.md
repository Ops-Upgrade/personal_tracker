## Brief overview
  Rules mandating strict adherence to DevSecOps principles and implementing the latest security best practices. Applies globally across all workspaces.

## Security-first development
  - When planning an implementation, strict adherence to DevSecOps principles is mandatory.
  - Always implement the latest and best security measures. Do not ignore common security vulnerabilities, especially in web-facing applications.
  - Consider the OWASP Top 10 and other industry-standard security frameworks when designing or reviewing any feature.
