# Security Policy

## Reporting a vulnerability

We appreciate responsible disclosure. If you believe you have found a security
issue, please report it privately rather than opening a public issue.

- **Preferred:** GitHub Private Vulnerability Reporting (Security tab on this
  repository).
- **Alternative:** contact the maintainers listed in `.github/CODEOWNERS`.

Please include enough detail to reproduce the issue: the affected component,
steps to reproduce, and the impact. Do not include personal data belonging to
other users.

## What to expect

- We aim to acknowledge reports within a week.
- We will keep you updated on triage and fix progress.
- This is a personal, free-tier project: there is no monetary bounty program,
  but reporters are credited in release notes if they wish.

## Safe harbor

We will not pursue legal action or file complaints against researchers who:

- test in good faith using accounts and data they own,
- avoid harming other users or their data,
- stop once the issue is demonstrated, and
- report privately and allow a reasonable window for a fix.

## Scope

This policy covers the web application and the public source code in this
repository. Issues in third-party services we depend on should be reported to
those providers.
